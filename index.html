    01
    Frame the decisionتحديد القرار
    Start from the decision someone needs to make, not from the model. Which branch gets stock? Which policy article applies?أبدأ من القرار الذي يحتاجه صاحب العمل لا من النموذج: أي فرع يُزوَّد؟ أي مادة تنطبق؟
    • stakeholders
    • CPMAI
    
      
    02
    Get the data rightضبط البيانات
    Clean, deduplicated, governed layers before any AI. Most failures I have seen were data failures wearing an AI costume.طبقات نظيفة ومُحوكمة قبل أي ذكاء اصطناعي، فأغلب الإخفاقات التي رأيتها كانت مشكلات بيانات بثوب الذكاء الاصطناعي.
    • Medallion
    • SQL
    • DAMA
    
      
    03
    Build and measureالبناء والقياس
    Agents, retrieval and forecasts are built with an evaluation harness from day one, so every change has a number.أبني الوكلاء والاسترجاع والتوقعات مع منظومة تقييم من اليوم الأول، فلكل تغيير رقم يُقاس به.
    • LangGraph
    • RAGAS
    • backtests
    
      
    04
    Ship and hardenالنشر والتحصين
    Containerised, scheduled, monitored and security-reviewed. A demo is not done until employees use it every day.حاويات وجدولة ومراقبة ومراجعة أمنية، فالنموذج التجريبي لا يكتمل حتى يستخدمه الموظفون يومياً.
    • Docker
